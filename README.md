# STG PROTO（仮題）

90 年代アーケードの縦スクロールシューティングを思わせる、ドット絵の弾幕シューティング。iPhone の Safari で遊ぶことを目標に、HTML 1 ファイル（`index.html`）で作っている。

現在は **M1「手触りの試作」**。自機・ショット・レーザー・雑魚 2 種・爆発・コンボ・弾消しだけが入っていて、敵の出現は約 32 秒周期でループする（周回ごとに弾が少し速くなる）。計画は [tasks/todo.md](tasks/todo.md)。

## iPhone で遊ぶ

1. https://kakankan677.github.io/shooting-game/ を Safari で開く。
2. 共有ボタン →「ホーム画面に追加」で、全画面のアプリとして起動できる。

## 公開

GitHub Pages で公開している（公開リポジトリ kakankan677/shooting-game、URL を知っていれば誰でも開ける）。`main` ブランチに push すると `index.html` がそのまま公開される。

## 遊び方

| 操作 | iPhone | PC |
|---|---|---|
| 移動 | どこかに指を置いてなぞる（指を動かした分だけ自機が動く） | 矢印キー / WASD |
| ショット | 触っている間、自動で撃つ | 自動 |
| レーザー（移動が遅くなる） | 設定で選ぶ: なし／2本目の指を置く／指を止める | Shift または X |
| 一時停止 | 右上の II | P / Esc |

- 自機の中心のピンクの点だけが当たり判定。
- 敵の近くで倒すと得点が 2 倍・4 倍になる。続けて倒すと CHAIN が伸びる（1.5 秒で途切れる）。
- 緑の中型機を倒すと、画面の敵弾がすべて金の星に変わって自機に集まる。

## 試し方（M1 で確かめたいこと）

1. 3 つのレーザー操作（なし／2本指／指を止める）を切り替えて、どれが一番気持ちよく遊べるか。
2. 指の感度（1.0／1.5／2.0）はどれがちょうどよいか。
3. 撃つ・壊す・中型機を倒したときの手応え（光・揺れ・止まり・音）は足りているか。
4. FPS 表示を ON にして、弾が多い場面でも 60 前後を保てるか。

## デバッグ

ブラウザのコンソールで操作する（URL の `?debug` / `?inv` / `?auto` でも同じ設定になるが、Claude デスクトップの内蔵ブラウザは file を data: URL で開くためクエリが消える）。

- `SG.dbg.invincible = true` … 無敵
- `SG.dbg.auto = true` … 弾を避けながら自動で動く（中型機はほぼ倒せない）
- `SG.stress(1000)` … 敵弾を 1000 発ばらまく負荷試験
- `SG.settings.fps = true` … FPS・弾数を表示

## 設計メモ

- **HTML 1 ファイル + Canvas 2D、外部依存なし**: 3D が要らないので Three.js も使わない。どこにでも置ける。
- **内部解像度 240×320 を拡大**: `image-rendering: pixelated` で拡大してドットを保つ。縦長の iPhone では、上にゲーム画面を画面幅いっぱいに置き、余った下側を「指を置く場所」にする。指で自機や弾が隠れない。
- **相対移動**: 指の絶対位置ではなく、動かした量で自機を動かす（`感度 ÷ 拡大率` 倍）。どこに指を置いてもよい。
- **ドット絵はコード内の文字列**: 1 文字 = 1 ドットとパレットからスプライトを生成する。画像ファイルがなく、すべてオリジナル。白く光らせる版も起動時に作る。
- **60Hz 固定更新**: 120Hz の画面でもゲーム速度が変わらない。ヒットストップは更新を数 tick 止めるだけで、画面の揺れはその間も続く。
- **オブジェクトプール**: 敵弾・ショット・破片・星は配列を使い回し、消すときは末尾と入れ替える。GC による引っかかりを避ける。
- **当たり判定**: 自機は半径 1.5、敵弾は見た目（直径 7／5）より小さい半径 2.0／1.3。「当たってないのに死んだ」をなくす。
- **桜井さんの考え方の当てはめ**（あーしの記憶ベースで、動画の出典は未確認）: 手触り（被弾の白い光・揺れ・ヒットストップ）、リスクとリターン（近距離撃破の倍率）、緊張と緩和（弾幕 → 撃破 → 弾消し）。

## 既知の制約

- iOS Safari は振動（バイブ）に対応していない。
- 音は最初のタップの後から鳴る（iOS の仕様）。画面を離れると一時停止して音も止める。
