# STG PROTO（仮題）

90 年代アーケードの縦スクロールシューティングを思わせる、ドット絵の弾幕シューティング。iPhone の Safari で遊ぶことを目標に、HTML 1 ファイル（`index.html`）で作っている。

現在は **M2「弾幕エンジン」**。M1 の手触りの試作（自機・ショット・レーザー・雑魚 2 種・爆発・コンボ・弾消し、約 32 秒周期でループし周回ごとに弾が速くなる）に、弾幕を組み合わせて書ける仕組みと、12 種類の撃ち方を見て fps を測る「弾幕ギャラリー」を加えた。計画は [tasks/todo.md](tasks/todo.md)。

## iPhone で遊ぶ

1. https://kakankan677.github.io/shooting-game/ を Safari で開く。
2. 共有ボタン →「ホーム画面に追加」で、全画面のアプリとして起動できる。

## 公開

GitHub Pages で公開している（公開リポジトリ kakankan677/shooting-game、URL を知っていれば誰でも開ける）。`main` ブランチに push すると `index.html` がそのまま公開される。

## 遊び方

| 操作 | iPhone | PC |
|---|---|---|
| 移動 | どこかに指を置いてなぞる（指を動かした分だけ自機が動く） | 矢印キー / WASD |
| ショット | 触っている間、自動で撃つ | 自動 |
| レーザー（移動が遅くなる） | 2本目の指を置いている間（既定。設定で「なし」「指を止める」にも変えられる） | Shift または X |
| 一時停止 | 右上の II | P / Esc |

- 自機の中心のピンクの点だけが当たり判定。
- 敵の近くで倒すと得点が 2 倍・4 倍になる。続けて倒すと CHAIN が伸びる（1.5 秒で途切れる）。
- 緑の中型機を倒すと、画面の敵弾がすべて金の星に変わって自機に集まる。

## 弾幕ギャラリー（fps 計測）

タイトルの「弾幕ギャラリー」で、12 種類の撃ち方を 7 秒ずつ順に流す（最後の STRESS は 12 秒で、弾が 2000 発前後まで増える）。この間は無敵で、自機は普通に動かせる。終わると結果画面に、パターンごとの最低 fps・最も長かったフレーム（ms）・最大弾数が出る。最初の 1 秒は前のパターンとの入れ替わりなので計測しない。早送りなどで測れなかった行は `-` と出る。

| 名前 | 撃ち方 |
|---|---|
| AIM FAN | 自機狙いの扇（7 発と 6 発を交互） |
| RING | 全方位の輪 |
| SPIRAL | 回転しながら撃ち続ける渦 |
| TWIN SPIRAL | 逆向きに回る 2 本の渦 |
| FLOWER | 曲がりながら広がる輪（左右に曲がる 2 色） |
| ACCEL RING | ゆっくり出て加速する紫の大玉 |
| STOP AND AIM | 広がって止まり、自機を狙い直して飛ぶ針弾 |
| RAIN | 画面上から降る雨 |
| NEEDLE BURST | 自機狙いの針弾の連射 |
| LINE WALL | 速さ違いを重ねた列弾の壁 |
| BOSS MIX | 輪・2 本の渦・針弾の扇を組み合わせたボス風 |
| STRESS | 負荷試験（遅い輪を積み重ねる） |

## 弾幕の書き方

敵の攻撃はジェネレーター関数で書き、`yield n` で n tick（1/60 秒）待つ。

```js
// 例: 回転する輪を 20 tick おきに撃ち、4 回に 1 回は自機狙いの針弾も撃つ
function* (e) {
  for (let i = 0; ; i++) {
    D.ring(e.x, e.y, 24, i * 0.13, { k: 1, s: 1.3 });
    if (i % 4 === 0) D.fan(e.x, e.y, D.aim(e.x, e.y), 5, 0.15, { k: 3, s: 2.5 });
    yield 20;
  }
}
```

- 撃ち方: `D.fan`（扇）、`D.ring`（全方位）、`D.line`（同じ向きに速さ違い）、`fire`（1 発）、`D.aim`（自機への角度）
- 弾の性質: `k` 種類、`s` 速さ、`acc` 加速、`sMin`/`sMax` 速さの範囲、`w` 曲がる角度、`wait`/`aim`/`s2`/`aimOff` 止まって狙い直す
- 弾の種類: 0 ピンク大玉、1 青小玉、2 ピンク小玉、3 青の針弾（進む向きに回る）、4 紫の大玉
- 速さと加速には難しさの倍率 `G.rank`（周回ごとに +0.1）が掛かる。自機がやられている間は撃たない

## デバッグ

ブラウザのコンソールで操作する（URL の `?debug` / `?inv` / `?auto` でも同じ設定になるが、Claude デスクトップの内蔵ブラウザは file を data: URL で開くためクエリが消える）。

- `SG.dbg.invincible = true` … 無敵
- `SG.dbg.auto = true` … 弾を避けながら自動で動く（中型機はほぼ倒せない）
- `SG.stress(1000)` … 敵弾を 1000 発ばらまく負荷試験
- `SG.settings.fps = true` … FPS・弾数を表示
- `SG.step(60)` … 描画を待たずに 60 tick 進める（早送りでの確認用。fps の計測にはならない）

## 設計メモ

- **HTML 1 ファイル + Canvas 2D、外部依存なし**: 3D が要らないので Three.js も使わない。どこにでも置ける。
- **内部解像度 240×320 を拡大**: `image-rendering: pixelated` で拡大してドットを保つ。縦長の iPhone では、上にゲーム画面を画面幅いっぱいに置き、余った下側を「指を置く場所」にする。指で自機や弾が隠れない。
- **相対移動**: 指の絶対位置ではなく、動かした量で自機を動かす（`感度 ÷ 拡大率` 倍）。どこに指を置いてもよい。
- **ドット絵はコード内の文字列**: 1 文字 = 1 ドットとパレットからスプライトを生成する。画像ファイルがなく、すべてオリジナル。白く光らせる版も起動時に作る。
- **60Hz 固定更新**: 120Hz の画面でもゲーム速度が変わらない。ヒットストップは更新を数 tick 止めるだけで、画面の揺れはその間も続く。
- **オブジェクトプール**: 敵弾・ショット・破片・星は配列を使い回し、消すときは末尾と入れ替える。GC による引っかかりを避ける。
- **当たり判定**: 自機は半径 1.5、敵弾は見た目より小さい（大玉 直径 7 → 半径 2.0、小玉 直径 5 → 1.3、針弾 1.2、紫の大玉 直径 11 → 3.5）。「当たってないのに死んだ」をなくす。
- **弾は角度と速さで持つ**: 加速・曲がり・狙い直しを 1 発ごとに持てる。性質が変わらない弾は計算を省き、毎 tick の三角関数は加速や曲がりのある弾だけで行う。
- **攻撃はジェネレーター**: `yield n` で待てるので、「撃つ → 待つ → 撃つ」をそのまま上から書ける。ボスの形態変化もこの書き方で表せる見込み。
- **針弾は 32 方向の絵を先に描く**: 毎回回転させず、進む角度に近い絵を選んで描く。
- **桜井さんの考え方の当てはめ**（あーしの記憶ベースで、動画の出典は未確認）: 手触り（被弾の白い光・揺れ・ヒットストップ）、リスクとリターン（近距離撃破の倍率）、緊張と緩和（弾幕 → 撃破 → 弾消し）。

## 既知の制約

- iOS Safari は振動（バイブ）に対応していない。
- 音は最初のタップの後から鳴る（iOS の仕様）。画面を離れると一時停止して音も止める。
